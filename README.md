# Calculadora de IMC

---

## 🎯 Objetivo

O projeto consiste em uma **calculadora de IMC (Índice de Massa Corporal)** simples, que permite ao usuário inserir seu peso e altura para calcular o valor do IMC e determinar sua classificação (baixo peso, normal, sobrepeso, etc.).  
A aplicação foi construída usando **HTML** para o front-end, **CSS** para o design, e **Python com Flask** para o back-end, permitindo manipulação de variáveis e funções para cálculo e interação.

---

## 🛠️ Ferramentas Utilizadas

- **HTML** – Estruturação da interface de entrada e saída de dados.
- **CSS** – Estilização da página, incluindo layout e design da interface.
- **Python (Flask)** – Lógica de cálculo do IMC, manipulação de variáveis e integração com o front-end.

---

## ✅ Conclusão

Esse projeto foi uma excelente oportunidade de aprender como integrar **HTML**, **CSS** e **Python** em uma aplicação web simples. Ao trabalhar com **Flask**, consegui aplicar conceitos de **manipulação de variáveis**, **funções** e **rotas** para entregar a funcionalidade de cálculo. Além disso, a experiência me ajudou a melhorar o entendimento sobre como o front-end e o back-end podem se comunicar de maneira eficaz.

### Aprendizados:
- Como usar **Flask** para criar uma aplicação web simples.
- Manipulação de **variáveis** e **funções** em **Python** para cálculos dinâmicos.
- Estruturação e **estilização** de páginas web com **HTML** e **CSS**.
- Como receber **inputs do usuário** e gerar respostas dinâmicas em tempo real.
